## 冻结的资金政策

用独立的假设 100,000 美元影子账户，股票目标预算固定为账户净值 10%，其余现金零利息。十个原策略名额各占账户 1%，同一行业最多两个；缺席名额留现金，不重新分配。这里的行业上限 2% 和个股上限 1% 都是再平衡目标，持有中的漂移可能突破。买卖成本必须纳入股票预算，后续账本需按父策略的成本后净值求解；当前预算工具只输出成本前示例，明确不可执行。

10% 是管理约束，不是文献推荐的最优值，也没有根据已见收益曲线拟合。缩仓不会提高选股胜率，不保证账户最大回撤。该账户尚未连接券商，不代表已有 Paper 余额、可用现金或持仓归属核验。
