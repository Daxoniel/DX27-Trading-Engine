# RI1：身份个案与非空持仓完整流程

本阶段解释了 RA1 中唯一的资产查询失败，并用明确标识的合成数据验证**原资格与排名 → 证据准入 → 非空持仓记账 → 后续换仓 → 独立审计**的完整流程。没有修改原策略、10% 目标预算、六周期评价或旧满仓 FAIL。

[方案](protocol.json)明确披露：初步身份搜索先于登记，不是盲测；登记后才进行进一步源文件抓取、代码封存与测试。演练前提交[执行哈希](code-seal.json)。所有此前跟踪文件及 156 个封存核心文件不变。

## 404 的可核实解释

[SEC 2026-05-21 的 8-K](https://www.sec.gov/Archives/edgar/data/1856437/000185643726000007/vsco-20260521.htm)说明，公司普通股从 **2026-06-02** 开盘起使用 VSXY 交易代码。[公司同日公告](https://victoriassecret.gcs-web.com/news-releases/news-release-details/victorias-secret-co-change-ticker-symbol-vsxy-marking-next)进一步说明 CUSIP 不变、股东无需采取行动。与之相符，RA1 留存的供应商 name-change 事件也是 VSCO→VSXY，过程日期为 2026-06-02，旧／新 CUSIP 相同。

本次以 GET 保存了 SEC 与发行人页面原始字节、请求／收到时刻和哈希，并检查下载内容包含已阅读的代码与 CUSIP 说明。单独请求当前 VSXY 的 Paper 资产元数据，返回 active／tradable。见[聚合身份个案记录](identity-case.json)。两个公告属于同一发行人的公告／披露，并非两个独立经济身份数据库。

这些证据支持“同一普通股更换交易代码”的解释，不能把原代码 404 等同于消失或自动剔除。**没有将 VSXY 加入固定归档池，也没有把旧价格、旧排名或 RA1 身份规则直接改名。** 原／新券商资产 UUID 的连续性及全历史价格映射尚未核实；本个案不能证明所有日期的可交易性，也不涵盖其他证券和公司行动。

当前身份材料的获取时间早于首次形成期，按既有 RA1 时间规则不能直接当作未来形成期的准入审查。正式接入时仍须重新取得相应窗口证据，明确经济身份键、行情请求代码与资产元数据代码之间的映射，然后单独登记适配。此次 formation-ready 身份数仍为零。

## 非空持仓测试做了什么

夹具明示为 SYNTHETIC_RI1：55 个虚构股票、五个行业、确定性日线与非恒定 FF3，绝不当成真实行情、公告或已发生的前向观察。使用登记的未来交易日仅是测试时钟。唯一替换的正向验证边界是原归档池哈希，以便有限的合成池进入测试；没有替换资格计算、QR、独立 Decimal 回归、排名、来源摘要、身份检查、日志头或会计审计函数。合成身份来源使用 example.invalid 并标识为假文档。

分别生成两次形成期完整原始／复权源文件、因子、资产及身份文档，真实调用 RA1 准入，核对四个选择器、两档成本的八本实际日志。每个账户每轮十个目标，按成本后净值每个 1% 执行代理再平衡；先入场，再每日估值，再携带既有持仓进入下一轮。夹具使部分旧持仓不在新目标中，验证卖出不能只检查新目标价格。

新增转换适配器只接受显式合成包，不能启用 Paper 或实盘交易。它重新运行准入、读取封存排名、不接受调用方任意目标；绑定形成期清单、执行收盘数据包及八个原日志头。执行包的日期必须是登记执行日，收到时刻须不早于该日收盘。全部八个案例验证通过之后才开始写账。

多日志写入不是数据库原子事务。逐案例核对预期状态、独立审计并写收据；只有全部完成才创建 complete 记录。若中途失败，保留 partial 记录和已有写入，不自动补写或重试。失败注入测试故意中断第二本账，确认既有写入可见、没有 complete、旧头不能再次提交；此处异常注入不用于绕过正向验证。

## 检查结果与限制

[可复算演练收据](rehearsal.json)显示：

- 两次合成形成期，各 55 只股票，110 组独立合格特征和 110 组独立评分检查；同一输入还会在准入时重新计算，不将重复检查称独立统计样本。
- 八本账各两次换仓，共 16 个账户转换；每本每轮十个目标。
- 两档成本与不同选择器累计有 70 个旧名额退出新目标，包含重复证券，不是 70 笔真实交易。
- 共 184 个账户日标记通过独立会计审计；仅验证工程行为，不公开或解读合成收益。
- 8 项新增测试覆盖正常非空两周期、缺目标价格、缺旧持仓价格、排名篡改、重复／过期头、缺身份文档、未解决行动、提前收盘数据、部分写入和拒绝真实模式；54 项父研究测试通过。

本次没有抓取真实股票价格、产生真实新排名、发送订单或安装调度器。正式前向观察数仍为零。上次因子检查缺少 2026-09，本次没有再次请求因子，不能声称它此后仍未更新。距离首次形成期尚有时间；本次工程通过不构成策略表现或可交易性验证。

```sh
python research/residual-integration/rehearse.py --output work/residual-integration/NEW-UNIQUE-REHEARSAL

```

演练完全离线，不依赖私有真实行情。身份个案抓取只需已有 RA1 私有公司行动快照、指定公共来源与 Paper 资产元数据 GET 权限。输出目录必须不存在。CI 在 Ubuntu、Windows 执行共 62 项测试和原字节封存检查；无凭据请求。所有逐股原始资料及完整合成账本留在忽略的 work/，公开摘要明确区分真实来源和虚构测试。
