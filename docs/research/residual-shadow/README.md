# RS1：影子账本与独立排名审计

本阶段补齐 **10% 股票预算下的离线记账、可重放日志和独立排名审计**。原 RM1a 选股规则未改变，RV1a 满仓版本的 FAIL 保留。未使用新行情，不重新发布策略收益，不向券商发送订单。

[登记方案](protocol.json)先于代码封存和旧数据演练提交；[执行哈希](code-seal.json)在演练前提交。沿用文献解释和模型约定见[父模型研究](../residual-momentum/README.md)，这里新增的是工程组件与行政研究门槛，不声称文献支持新的最优仓位。

## 资金与账本

每本假设账户独立以 100,000 美元开始。每个入选名额占成本后净值 1%，最多十个名额、每个原归档行业最多两个；未占用名额留现金。成本取单边 5bp 与 25bp，按买入与卖出的绝对成交名义金额收费，通过自融资方程求解成本后净值。每日持仓允许漂移，因此 10%／1%／2% 都是再平衡目标，不是持续风险上限。

使用复权收盘价及零碎的代理单位，与券商真实股数和成交不同。现金零利息，期末仅估值、不强制卖出。账本不能处理未定价 CVR、公司行动应收款或证券身份迁移；上游出现这些问题必须阻塞，不能把复权价格当成真实券商会计。

日志按序号独占创建文件，每条记录绑定前一条 SHA256、输入快照摘要和再平衡排名摘要。重启时检查序号与哈希链，并从首条事件重新计算状态。缺一个持仓／目标价格，或预定再平衡日没有排名计划，都会记录 HALT，拒绝后续记账；不前向填充、不静默跳过交易日。部分写入、文件丢失或篡改均停止重放，不自动修复历史。

哈希链用于发现一致性问题，不能阻止有权限的人重写整个目录，也不能证明源数据真实、输入按时可用或目标可成交。当前组件仅接受离线工程输入，没有前向准入、券商连接或订单接口。

## 独立审计

排名适配器重新计算原 SM1 基础资格；父审计另核对全部合格行的历史特征。对整个原合格池逐股计算 RM1a 分数，按原约定只排除历史缺失或分散度过低的股票，其余计算失败均中止。独立 Decimal 正规方程回归与原 QR 的分数、系数、窗口必须一致；新增有限值检查避免 NaN 绕过数值容差。

随后用独立分数重新排序，以原规则检查十个名额、行业上限及代码平分处理，并与父选股器比较最终成员。微小数值差异若改变入选集合，也会中止。该审计不认证经济股权身份；固定归档池及其历史局限仍在。

账本另有一个不调用生产成本求解器或状态更新函数的审计器，独立重建单位、现金和净值，核对成本、自融资方程、目标比例、每日净值及回撤。另与封存父引擎的浮点账目逐日对比。

## 已完成的旧数据演练

全部输入来自先前已暴露的 RV1a 2026 年数据，只复用该区间已登记的接缝规则与隔离证明，不将隔离名单推广到未来。[完整聚合记录](rehearsal.json)显示：

- 重算 9 次形成期、4 组选择器；36 组入选集合与原存档完全一致。
- 独立复核 2,958 条合格特征、2,790 组回归分数。
- 四个选择器各两档成本，共 8 本账，全部完成 188 个每日标记、9 次再平衡；合计 1,504 个每日标记，各通过独立会计审计。
- 与独立父引擎浮点参考的现金／股票名义值／净值最大差约 4.37e-11 美元。
- 9 项新测试及 36 项既有测试通过；另验证跨进程／不同哈希种子重放与六个计划周期的交易日。

这些数字是工程检查次数，包含同源重复案例，不能视作独立统计样本或前向验证。逐股排名、价格和详细账本只存私有 work/；公开记录只含聚合计数与摘要。

## 前向评价已登记，尚未启动

计划形成期为 2026-10 至 2027-03 的六个月末，终点为 2027-04-30。每个形成期使用第二个后续 XNYS 交易日收盘代理成交，输入与排名须在该交易日开盘前封存；六期[交易日与 UTC 时刻](calendar.json)已核对。首次计划执行日仍为 2026-11-03。

四个选择器均用相同预算及两档成本独立记账，不能只展示最弱对照。任何跳过周期、缺失数据、未解决证券身份、未封存排名或账本 HALT，整段评价记为 INCOMPLETE，不移动终点补样本。完整后才按登记条件判断研究 PASS／FAIL：两档成本下，因子调整组净收益为正且超过 matched ordinary，账户每日回撤不超过 5% 且不超过 matched ordinary。5% 是新预算版本的行政研究门槛，不是将原满仓门槛改宽，也不是概率保证。

六周期结果不构成显著性检验，不证明持久 alpha；个股正收益区间仅作描述，不能称真实交易胜率。即使 PASS 也不会自动转 Paper 或实盘。

**当前仍为阻塞状态，前向观察数为零。** RF1 收据显示因子只到 2026-08，而首次形成期需要 2026-09；本次没有重新抓取，不能据此断言源文件之后一直未更新。还需接入带真实获取时间的行情／因子快照、证券身份与公司行动检查，以及形成日至执行截止时间的准入控制。未安装常驻调度器，未读取或修改 Paper 账户。

python -m pip install exchange_calendars==4.13.2
