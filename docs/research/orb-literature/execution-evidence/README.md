## Paper 与数据权限的边界

[官方Paper说明](https://docs.alpaca.markets/us/v1.4.2/docs/paper-trading)说明模拟撮合不计市场冲击、延迟滑点、排队等实际因素及监管费，也不按显示量限制撮合。因此Paper可用于接口/生命周期测试，不能据其成交证明真实成本。文档中Paper使用NBBO模拟撮合，与用户获得什么行情权限是两件事；不能由模拟成交倒推出用户拥有合并报价。

[官方Market Data计划](https://docs.alpaca.markets/us/docs/about-market-data-api)区分：Basic实时股票覆盖IEX，完整实时覆盖属于另一计划；历史接口有最近15分钟限制。该说明支持继续优先用已有旧数据和离线工具，不需要为本轮工程验收购买实时订阅。它不是本账户的实际权限验证，也不保证任何新历史报价请求成功。没有把IEX当成SIP的可替代数据源。
