# RD1 results and boundary

Six new tests exercise the existing RS1 ledger and independent auditor on explicitly fabricated prices and eight local hypothetical accounts. The successful path enters on 2026-11-03 and marks held positions on 2026-11-04 using synthetic future clocks. It is not a prospective observation, strategy performance test, AA1 production admission, or broker fill. A simulated second-account disk failure leaves one confirmed append and an explicit partial receipt; further updates are blocked. Multi-account writes remain non-atomic and concurrent writers unsupported.

The read-only actual-clock preflight is retained in preflight.json. It reads no provider credentials, sends no source requests and writes no journals. After formation it remains blocked because this increment deliberately exposes no production adapter.

The overlap guard rejects a changed previous close for any held name; it does not prove continuity of every historical adjustment. Corporate action review is explicitly synthetic. Real daily admission still needs raw source receipt validation, fresh action/identity evidence, retained pre-open AA1 decision binding, a complete price-vintage policy and a single-writer lock. These are required before connecting this harness to real source packets. No automated Paper promotion or scheduler has been enabled; the registered strategy and its prior drawdown failure are unchanged.

Run `python -m unittest discover -s research/residual-daily -v` and `python research/residual-daily/preflight.py`. All prior research modules run in separate processes in the new two-OS CI workflow. Source code and the preregistered protocol are hashed in code-seal.json.
