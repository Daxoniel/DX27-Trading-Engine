## 1. 一分钟延迟不是一个固定滑点数字

上一轮只确定：在R0附近，DELAY_1M相对R0在A少赚$731.37、B少赚$1,045.68。为解释差值，本轮对共同交易匹配方向，按如下恒等式分解参考价毛损益：

设q0/q1为原/延迟股数，i0/i1为入场参考价，o0/o1为退出参考价，s为方向（多+1、空−1）：

`Δgross = −q0*s*(i1−i0) + q0*s*(o1−o0) + (q1−q0)*s*(o1−i1)`。

再减两组佣金差；对只出现在原记录的交易取负原净损益，对新增交易加延迟净损益。它覆盖所有交易，不只选择共同且有利的日子。此拆分以q0作基准，交互项放在数量/资金分项，**不是唯一因果分解**；换基准会改变分项，但总和必须相同。

| 相对R0的变化，USD | A | B |
|---|---:|---:|
| 共同交易入场参考价分项 | −559.61 | **+142.87** |
| 共同交易退出参考价分项 | +689.19 | −914.56 |
| 股数变化及资本路径分项 | −2,173.83 | −681.66 |
| 佣金差分项 | +0.38 | +0.14 |
| 不再入场的原交易分项 | **+1,312.49** | **+407.53** |
| 新增延迟交易分项 | 0.00 | 0.00 |
| 合计净变化 | **−731.37** | **−1,045.68** |

A共同239笔，其中126笔入场方向价格变差、112笔变好、1笔不变；8笔退出原因改变。B共同60笔，26笔入场价格变差、34笔变好，2笔退出原因改变。被取消的12/3笔在原路径合计是亏损，取消它们产生正分项。不能把“取消交易”或“B买贵卖便宜”当总亏损的既定解释。

固定拆分下，A的负分项主要是数量/资金路径；B有较大退出价格与数量/资金负分项。延迟改变风险距离、10R、股数和资本衔接，退出变化也可能来自目标和持仓路径改变；本轮未进一步隔离每个机制，不能把数量/资金一项全部解释为仓位计算错误或纯资本反馈。它更不能说明实际改为09:35成交便可获得收益；09:35理想开盘参考价没有可执行价格证明。

## 2. R1 实际上是名义仓位上限主导

用原R1每日起始权益、真实记录入场参考价、首五分钟低点和上一分钟成交量，分别求出：含入场费的现金可买股数、25%名义上限、1%上一分钟量上限、0.25%含预计双边费用的计划止损风险上限。对145笔实际入场逐一验证：实际数量等于这些上限的最小值。

| 项目 | A（115笔） | B（30笔） |
|---|---:|---:|
| 名义上限为最小整数股数 | **115** | **30** |
| 其中仅名义上限最小 | 114 | 30 |
| 其中名义/风险整数上限并列 | 1 | 0 |
| 现金或量上限为最小 | 0 | 0 |
| 计划止损风险中位数，占当日权益 | **0.0682%** | **0.0811%** |
| 计划止损风险均值 | 0.0765% | 0.0853% |
| 计划止损风险最大值 | 0.2466% | 0.1732% |
| 实际入场名义仓位中位数 | 24.6851% | 24.6021% |

这里“上限绑定”是相同最小整数股数的含义；并列组不能归给唯一限制，逐项放松的边际效果没有测算。风险百分比是按正常止损和模型费用计算的计划值，不是跳空最大损失保证。

这说明代码按声明约束定仓，没有发现漏用风险预算的错误；但把R1描述成“每次承担0.25%风险”不准确，那是上限，实际通常低很多。R0最多4倍与R1最多25%账户名义敞口不能当作同尺度收益比较。**不能因此提高仓位去追平R0收益**；仓位放大不会创造已不存在的单位成交额优势，也会改变资金/费用路径。

## 3. 毛优势小于声明成本，不等于实际账户成本已被证明

按R1原固定成交的双边参考成交额归一：A毛损益约 **−0.1683bps**，B约 **+0.9469bps**；声明总成本约 **2.1427/2.1428bps**。这是历史路径的算术，不是未来期望收益或可接受费率阈值。

A成本前已负，B小幅正毛利被模型成本超过；两者都不支持“改低费率或加杠杆自然盈利”。模型中的$0.0035/股、$0.35最低费参考IBKR，不能认证为当前Alpaca账户适用费率。真实佣金、监管费、借券、点差和冲击必须分别核实；零佣金也不等于零摩擦。

本轮尝试复查Alpaca官方paper与market-data文档，两个请求均返回HTTP403，见[来源检查](official-source-check.json)。既有费用抓取还包含Page Not Found内容，不能当有效费表。此次没有核实账户、费率计划、地区/实体、报价权限或paper与真实执行偏差，不宣称完成成本校准，也未绕过访问限制、购买数据或提交订单。

## 4. 对方案的实际影响

- 撤回“把一分钟延迟缩短即可恢复收益”的简单归因。先定义数据完成、收到数据、决策、可提交意图和报价可得的事件时间，不能以整分钟标签代替真实延迟；无证据时保留旧09:36压力假设，不把09:35 open包装成可执行成交。
- 保留提前五分钟平仓作为既有项目约束，不把它当已确定的拖累，不因模型中更好就选作盈利候选。现有对照仅覆盖R0附近，R1迁移和交互仍未知。
- 报告实际风险与名义/量/现金限制，而不是靠上调上限补收益。R1原风险与仓位默认值暂不改。
- 多空收益不对称说明“只做多不是无影响迁移”；它不证明卖空实际可得，更不授权直接恢复多空、切TQQQ或提高杠杆。
- 暂停继续组合改参和训练；优先补足账户成本与执行时间证据。随后才决定是否有必要在R1约束下做有限的、另行固定的探索对照。所有新候选都需另行新样本/前瞻确认。

本轮没有精确估计真实市场原因；结论是对模型机制和证据缺口的审查。方案v2将这些限制变成明确工作项及阻断条件，而不是把未知项填成有利数值。
