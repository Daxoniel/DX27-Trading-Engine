# 策略优化第一项：单一RVOL过滤的完整结果

2026-10-19。用户要求把重点转向策略优化后，公开固定[本轮规则](../../research/orb-literature/rvol-exploration.json)和代码，再计算已暴露A/B上的一个改动：冻结QQQ/R1增加首五分钟RVOL≥1；分母为此前14个交易日同窗口成交量均值，不含当天。没有窗口/阈值搜索，未组合新指标、恢复空头、增加杠杆或降低成本假设。

**结论：结果混合，暂不把该过滤器晋级为Paper交易策略。** A期仍亏损且毛优势恶化；B期为正但只有8笔交易。减少交易可以减少成本和回撤，却不等于产生稳定的选时优势。这也不是对个股论文的等价复现或新样本外验证。

## 依据与迁移假设

Zarattini、Barbon、Aziz，[A Profitable Day Trading Strategy For The U.S. Equity Market](https://concretumgroup.com/wp-content/uploads/2026/02/A-Profitable-Day-Trading-Strategy-For-The-U.S.-Equity-Market.pdf)，已归档PDF pp.14–16定义开盘同窗口14日RVOL及至少100%的筛选，并进一步选择top-20个股。原文求和下标印成t−1，本轮按此前已披露的t−i解释；版本哈希见本轮规则及[文献核查](../../research/orb-literature/review-2026-10-16.md)。

该论文交易个股股票池、方向一致的突破stop入场、日线ATR止损及日终退出；这里仅测试把同窗口相对成交量作为QQQ定时方向规则的交易资格过滤。没有复现个股池、top-20或整套规则，不能把论文Sharpe作为QQQ效果证据。阈值1和窗口14来自该规则定义，并非根据本轮收益选择。

A净损益比原组改善262.37美元，但毛损益恶化462.69美元；总模型成本减少约725.06美元，抵消毛损益恶化后才得到净改善。这是账目分解，不把它解释为过滤器已产生正毛优势。B净改善580.46美元，毛损益也改善；但只有8笔，7月仍亏344.66美元，8/9月分别盈利374.96/374.30美元。两个阶段不支持一致的稳定选择机制。

固定成交额、额外每次成交方向增加0/1/2/5bps时，A过滤组净损益依次约−1041.47/−1267.27/−1493.08/−2170.49美元；B为+404.59/+365.27/+325.95/+207.97美元。这只是固定成交的摩擦压力账，不是重新模拟、实际成本估计或正式显著性门槛。逐月和全部组的完整指标在[A报告](stage-a.json)与[B报告](stage-b.json)。
