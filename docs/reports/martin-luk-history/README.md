上表合计 3,877。缺五分钟柱可能是无成交、停牌或数据覆盖不足，不能一概说是
供应商丢数据，也不能填成虚构交易。此处的历史完整性是入场前已知信息。

代码检查也发现需要重新审查的**量化映射**：本版在支撑共振、首次回调等条件
全部过滤之后，才要求同板块至少两只股票。因此“板块强势”实际上变成了
“同板块两只股票同日同时符合整套入场前条件”。这比原材料中的主题观察更窄。
0.5% 共振、160 日每根五分钟柱齐全等精确约束也是我们的实现定义，
不是本人公布的完整机械规则。

这些发现支持下一轮先审查文献到代码的映射；本轮保持原规则，未尝试放宽条件
挑选更好看的收益。任何新定义都需要另立版本与协议，不能替换本次结果。

## 为什么还不是完整全市场回测

- 股票池来自在 2025 年已公开的固定归档，不按今天是否存活筛选；但没有此后 IPO、
  历史每日证券资格与行业变动的完整记录。名称匹配也不等于证券类型认证。
- 在 62,972 个可比较的完整正常时段股票日中，供应商日线与五分钟聚合收盘价
  有 47,388 个不一致；开盘有 9,094 个，最高/最低分别有 302/282 个不一致。
  差异阈值为相对 1e−8。初筛以日线价格为必要条件，因而无法认证未进入初筛
  的其他证券没有被这种价格口径差异漏掉；不能把这些结果解释为完整 MLP1 的机会总数。
- 公司行动数据的首次可用时点、退市/并购结算全覆盖，以及报价级可成交性尚未核清。
  5bp 是总成本情景，券商实际佣金、监管费及滑点没有逐项核验。
- 方法来自复盘 2025 年的公开材料，本次是回顾性诊断，不是独立样本外检验。

因此**未通过 Paper 晋级条件**。完整动态 PIT 回测仍有数据缺口，当前不能宣称完成。
