2026-10-14 已继续执行行情前置检查：latest bars 的 SIP 请求返回 HTTP 403；
IEX 请求返回 HTTP 200，但三个标的最新分钟均属于上一交易日。该结果仅验证
REST latest endpoint，不是 WebSocket 订阅或实时接收验收。目前市场尚未开盘。
历史 SIP 下载成功不意味着实时 SIP 订阅成功。现有 RVOL 历史分母来自 SIP，
不能将 IEX 开盘成交量直接用于该分母；不自动切换 feed 或开启下单。
[P1 前置检查](../reports/intra-1a-real/p1-feed-preflight.json)保留脱敏状态和时间。
后续恢复实时路线时，需完成同一 SIP feed 的权限与订阅验收。

验收需要真实订阅权限、重复/乱序/迟到/修订处理、交易日与提前收盘、跨日重置、
历史预热、断线补齐和重启去重证据。历史数据的假设可用时间不能冒充实时接收证据。
行情 feed 必须显式记录；SIP 开盘均量不得与 IEX 分子混用。

## P2 — 自动模拟交易
