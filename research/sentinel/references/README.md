# Sentinel reference library

Stable IDs join source definitions, sensor contracts, research protocols, and code. `library.json` records exact verification scope; `sensor_links.json` covers all 19 feeds and 18 sensors against the frozen protocol digest. The immutable G protocol and H descriptor shape are preserved through this versioned sidecar.

Official documentation establishes meaning and units, not a validated live binding or predictive power. Local formulas cite local design separately from source definitions. Blocked constituent contracts have only a design reference until their PIT sources are admitted. Sector directory references are discovery entries, not verification of each fund. The VIX methodology full text was blocked by HTTP 403: its title/summary were verified by search, with the daily-close source independently captured.

Never reuse an ID for a different document. Changes require reviewed metadata/version/hash updates. Local source captures remain outside Git; publish only metadata/hashes, not licensed raw series.
