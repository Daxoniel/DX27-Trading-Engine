# R0 锚定的三个单因素探索对照

2026-10-16。A/B 已公开且已用于诊断，结果知情；此协议不是确认性收益登记。公开协议、脚本及构造测试并核对远端字节后，才重放固定旧数据。无新行情、无交易部署、无候选选优。问题来自[文献核查](../../docs/research/orb-literature/review-2026-10-16.md)和[固定产物诊断](../../docs/reports/orb-fixed-artifact-diagnostics/README.md)。对照设置是项目选择，不是论文认可的实验标准。

## 固定四组与解释

| ID | 唯一规则变化 | 用途 |
|---|---|---|
| R0 | 无 | 必须精确还原各期原R0明细 |
| LONG_ONLY | 首五分钟跌时不入场 | 重新传递每日资本的只做多模型；不是直接删除原空头损益 |
| DELAY_1M | 最早入场从09:35改09:36 | 用新的入场参考价重算R、股数和10R；非正R仍拒绝交易 |
| EARLY_CLOSE | 剩余仓位在收盘前5分钟open参考价平仓 | 改变持仓结束时点；其前触及止损/目标仍照旧退出 |

每组独立初始$25,000、每日资本衔接、QQQ、多空（LONG_ONLY除外）、1%账户价格风险预算、4倍名义上限、首五分钟另一端止损、10R、$0.0005/股/填单、无最低佣金/点差/滑点。不增加R1的25%名义、0.25%风险或成交量限制，不测试借券。它们是**R0理想模型附近**的单因素变化，不能把效果直接搬到R1成本/约束下。

不做组合或交互实验，不把三个差值相加解释R0−R1总差；没有估计方向×时点等交互，也没有研究仓位和费用改变的单独影响。LONG_ONLY会改变资本路径，变化不等于原多头分组贡献。EARLY_CLOSE在不利跳空止损/有利跳空目标之后、分钟内high/low触发之前执行，沿用已披露R1对应优先级；因此该因素包括这一固定退出执行约定。所有时间以实际交易日历为准，包括半日市。

A/B分开，各组报告净收益、毛净损益、费用、分钟末最大回撤、交易数、无交易日、持仓分钟比例、歧义次数、逐日权益与不交易原因。报告三个相对R0的收益差（百分点）及同日交易方向/有无交易变化数量。原审计工具附带的0/1/2/5bps固定成交额成本情景全部保留；无重采样/显著性检验、收益门槛、最好版本、按结果删日或续搜。负结果同样公开。

这是带资金反馈的确定性模型对照，仅能说明固定历史与假设下的敏感性，不能证明真实市场因果、统计显著或未来盈利。低佣金、零摩擦、多空可得性和分钟路径均理想化；未校准现实成本，不据此启用空头或提高杠杆。任何下一候选仍需另定新样本或前瞻协议。
